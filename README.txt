追加内容
・りんごと名前が一緒に小さくゆらゆら揺れます。個別に速度とタイミングが異なります。
・雲3つが木の後ろをゆっくり流れます。
・新規登録の登場演出と揺れは別の要素で動くため両立します。
・OSの動きを減らす設定に従い、対象環境ではアニメーションを止めます。

Xへ画像を投稿
1. 管理画面で月を選び「X用画像・投稿画面を開く」を押します。
2. 「前の木」「次の木」で対象を選びます。この画面では木は自動で切り替わりません。
3. 「この木の投稿画像を作る」を押します。選んだ木1本を1080×1080のPNGにします。
4. 表示された画像を確認します。
5. 「画像を保存」で保存し、「Xに投稿」で投稿文を開いて画像を添付します。
スマホで「画像を共有（Xなど）」が表示される場合は、共有メニューでXを選んで画像を渡せます。
共有先の候補や画像の受け渡し可否は端末・ブラウザ・Xアプリにより異なります。
「Xに投稿」リンクは画像を自動添付しません。Xへの投稿の確定はユーザーが行います。
画像は端末内で生成します。Xへ勝手に送信・投稿する処理はありません。
保存画像は揺れを一時的に止めた静止画です。PNGにアニメーションは含まれません。
ブラウザ上の文字描画や影とPNGでは見た目に若干差が出ることがあります。
